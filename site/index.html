01 / CONNECT THE MCP

A small config.
A useful feedback loop.

Install uv, then merge this template into your agent’s MCP configuration. It launches Anumana locally using uvx.

Replace the DSN placeholder locally with your own read-only PostgreSQL connection. Keep credentials out of source control.

Python 3.10+. The first launch downloads the pinned PyPI package. Clients using another config format need the same command, arguments and environment settings.

MCP configuration template
{
  "mcpServers": {
    "anumana": {
      "command": "uvx",
      "args": ["anumana-mcp==0.2.1"],
      "env": {
        "ANUMANA_DSN": "REPLACE_WITH_READ_ONLY_POSTGRES_DSN",
        "ANUMANA_ENGINE": "postgres"
      }
    }
  }
}

A FEW GOOD QUESTIONS

Before you connect.

Useful estimates.
Clear boundaries.

Does Anumana execute my query?

The SQL preflight tools ask the planner with EXPLAIN, never EXPLAIN ANALYZE. Anumana does not provide a query-execution tool. Live setup still requires access to your database for planning and schema discovery.

Why use a skill if the MCP already exists?

The MCP provides capabilities. The skill supplies a consistent workflow: inspect schema, check the candidate, review caveats, then refine. The server can be used without the skill; the skill needs access to the server’s tools for live planner checks.

Does “cost” mean runtime or a database bill?

For PostgreSQL, cost is the planner’s unitless estimate. It is not milliseconds or dollars. Offline checks are heuristic. Replanning can compare estimates, but cannot guarantee runtime or prove two queries return the same result.

What am I paying for on Agensi?

Any paid listing covers the packaged skill workflow and setup resources. The Anumana MCP server remains free and MIT licensed. Pricing will appear on the marketplace listing when it is published; no hosted service or exclusive server feature is included.

Will the skill and server update automatically?

The setup template pins server version 0.2.1. Upgrading requires a configuration change. Locally installed skill files also need updating; marketplace-delivered updates depend on Agensi’s installation and update flow.
